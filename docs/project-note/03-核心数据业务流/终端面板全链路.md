# 终端面板全链路

每个标签页一个真实 shell，面板位于 composer 上方。**Rust 拥有终端**：注册表、工作目录、shell 选择、进程树、输出编号与缓冲、流控全在 `src-tauri/src/terminal/`。webview 只发 tab id、按键、尺寸和视图状态。

## 触发点

| 触发 | 入口 | 前置 |
|---|---|---|
| 打开面板 | 面板头 ✕ / 切换快捷键（`desktop.terminal.toggle`）/ 状态栏按钮 / `/terminal` | 标签页已注册 |
| 首次 spawn | `useTerminal` 检测 `needsSpawn(entry)` | 面板打开 **且** xterm 已挂载且尺寸已 fit |
| 重启 shell | 退出后按 Enter（`canRestart`） | 上一实例已退出或 spawn 失败且无在飞 open |
| 关闭标签页 | `close_tab` | — |

## 数据流路径

### 输入方向

```
xterm onData（用户按键）
  → keymap 先判 guestShouldBypass：需要交给应用的键直接返回 false，不进 pty
  → OMP_BRIDGE.terminalWrite(sid, data)
  → terminal_write（同步命令）→ 有界通道(1024) try_send
      └ 队满 → 返回 "terminal input backlog"（绝不阻塞）
  → writer 线程按序写 master → shell
```

### 输出方向

```
shell → pty master
  → reader 线程（8 KiB 块，EINTR 重试）→ 队列(64 块)
  → pump 线程：合并、编号 seq、写入输出环，再 emit
      · 间隔 ≥ 4 ms，单帧 ≤ 64 KiB，base64 编码
      · 未 ack > 512 KiB → 停止出帧且停止排空队列 → reader 阻塞 → pty 反压 shell
      · ack 降到 < 128 KiB 或 replay 归零 → 恢复
  → emit terminal://data/{id} {instance, seq, b64}
  → OMP_TERMINAL_STREAM reducer → write(bytes) → xterm 解析完成回调 → terminal_ack
```

### 同步 reducer（`app/terminal-stream.js`）

```
数据帧 {instance, seq}
  ├ seq <= lastSeq          → 丢弃
  ├ instance > 当前         → 采纳新实例（lastSeq=0，xterm 已被 respawn 重置），并重取状态
  ├ seq == lastSeq + 1      → write + ack（live 帧才 ack）
  └ seq >  lastSeq + 1      → 请求 replay(afterSeq=lastSeq)，该帧标记 replayed 重新排队
replay 期间到达的数据与 exit → 全部进 pending 队列
replay 应答 → 无 ack 写入、lastSeq 推进到 headSeq（永不回退）、dropped 且 afterSeq>0 → 写一行「[output skipped]」
```

## 关键节点详解

| 节点 | 位置 | 核心逻辑 | 异常处理 |
|---|---|---|---|
| 标签注册 | `start_session` → `register_tab` | 先注册再 spawn omp；重复注册保留 shell 槽位 | 未知 id 一律拒绝 |
| open 流程 | `terminal/mod.rs` `open` | 六步无生命周期锁：校验尺寸 → 查表 → `Spawning`/`Live` 直接返回 → 解析 shell → 锁内设 `Spawning` → 无锁 spawn → 复查槽位后装 `Live` | 期间标签关闭 → 关掉刚 spawn 的 shell 返回 `tab closed` |
| shell 选择 | `shell::resolve_shell` | 设置里的路径（不可用则**报错**，不回落）→ `default_shell()`（unix `$SHELL` → 登录 shell → `/bin/sh`；Windows `%ComSpec%` → `cmd.exe`） | — |
| 环境 | `shell::apply_env` | `TERM`、`COLORTERM`、`OMP_DESKTOP=1`、`OMP_DESKTOP_SESSION=<id>`、扩展 PATH | macOS 缺 locale 时补 `LANG=en_US.UTF-8` |
| 退出 | waiter 线程 | Unix `waitid(WNOWAIT)`（观察但不回收，保留僵尸以固定 session id）；Windows `child.wait()` | `READER_GRACE` 250 ms 后仍无 EOF 则丢尾部输出，照常发 exit |
| 树杀 | `kill.rs` | 先 `SIGHUP` 到进程组 + 200 ms 宽限，再按 session id 反复 `SIGKILL`（最多 8 轮） | Windows 走 Job Object（`KILL_ON_JOB_CLOSE`） |
| ConPTY 启动 | `portable-pty` | 首帧是光标查询 `ESC[6n`，xterm 必须在 `onData` 里应答 | 首帧必须到达 xterm（输出环 replay 兜底） |

## 异常路径

| 异常 | 处理 |
|---|---|
| Windows 低于 10 1809（无 ConPTY） | `terminal_open` 拒绝（`portable-pty` 会 panic 并 abort 整个应用） |
| 尺寸非法 | 返回 `invalid terminal size CxR` |
| 标签未注册 | `no tab {id}` / `terminal_status`、`terminal_replay` 返回 `null` |
| 无可用目录与 Home | `no folder for the terminal: the home folder is not set` |
| 设置的 shell 已失效 | `open` 失败并返回原因（不回落到默认 shell） |
| spawn 失败 | 写入 xterm 并按"已退出"呈现，Enter 可重试 |
| replay 落后太多 | 输出环淘汰 → `dropped: true` → 写「[output skipped]」 |
| 前缀丢失（webview 重载） | 启动时 `close_all_tabs` 结束上一文档的所有 shell，恢复的标签页拿新 shell |
| 关闭时 shell 有后台任务 | `SIGHUP` + 200 ms；忽略 HUP 的进程付满宽限期后被 `SIGKILL` |
| Unix 上 shell 退出后 pid 可能被复用 | 故意保留僵尸进程（`WNOWAIT`），使 session id 始终有效 |

## 安全边界

- shell 以用户完整权限运行，omp 的审批模式与审批规则**不适用**于终端输入。
- agent 无法读写终端，终端输出也不进提示。
- Rust 只接受已注册标签页 id；工作目录由 Rust 自己选；唯一的可执行文件设置经"绝对路径 + 可执行"校验后持久化。
- 信任边界仍是 webview 的 JS 完整性。
