# 会话全生命周期

"会话"= 一个标签页 = 一个 omp 进程 + 一个 Chromium + 一个终端 shell。本流程覆盖：打开、切换、重启、关闭、启动恢复。

## 触发点

| 动作 | 入口 | 前置条件 |
|---|---|---|
| 新标签页 | `Ctrl+T`（`desktop.tab.new`）、`+` 按钮、侧栏最近项目、`openSession` | 有可用 profile；磁盘上存在文件夹时优先校验 |
| 恢复会话 | 历史面板 `resumeSession` / `--resume` | `sessionFile` 通过 `saved_sessions::validate_resume` |
| 启动恢复 | webview 启动后 `_restoreOpenTabs`（`live.js:1792`） | `restoreTabs` 设置开启（默认开） |
| 切换标签页 | 点击 / 键盘 / 手机端选中的标签 | 无需前置，但会触发快照与重放 |
| 重启（profile 切换 / 审批模式） | `_respawnSession`（`live.js:1308`） | 空闲（busy 标签延后到 `get_state` 显示空闲） |
| 关闭 | `closeSession` → `_closeTab` → `close_tab`（`lib.rs:370`） | `confirmBusyClose` 开启时繁忙标签需确认 |

## 数据流路径

### A. 新标签页

```
openSession(cwd, profile?)
  → live.js _startProjectSession(cwd, {activate, remember})   live.js:1596
    → 生成 id `session-<ms>`（单调计数器 _lastSessionMs）
    → sessionRegistry.set(id, {path, profile, name, sessionFile:null, …})
    → _spawnSession(id, cwd, {resume, profile})               live.js:1137
      → invoke("start_session", StartSessionArgs{...})        lib.rs:103
        → ApprovalModeStore::resolve(cwd)                      → 具体模式（项目覆盖优先）
        → TerminalManager::register_tab(id, folder)            ← 先于 spawn，失败也能用终端
        → BrowserManager::allocate_if_available(id)            → 占位端口 + <cache>/browser/<pid>/<id>.yml
        → spawn_omp(cwd, resume, profile, mode, overlay)       agent/spawn.rs
          → 版本闸 MIN_OMP_VERSION 检查（只缓存通过结果）
          → args: --mode rpc-ui [--profile] [--resume] [--cwd] --approval-mode=<m> --config=<overlay>
        → AgentBridge::start_session(...)                      agent/mod.rs:184
          → 锁内 insert BridgeInner，同时清旧会话 alive → 锁外 reap_and_clear_grants
          → 起 stdout reader + stderr reader
        → widget_host.session_started(id, project)
        → start_git_watch(folder)
      → 成功后：recent_projects_touch(cwd)、registry 记 processStartedAt
      → 若 activate：await _switchToSession(id)
```

### B. 切换标签页（核心同步路径）

```
_switchToSession(id)                                          live.js:883
  1. myGen = ++_switchGen
  2. _saveCurrentSession()        — 把当前 state 存进 sessionRegistry 快照
  3. await 所有 activeListeners 的 unlisten  →  每次 await 后检查 current()
  4. activeSessionId = id
  5. _restoreSession(id) 或 _resetSessionVars()
  6. _replayBuffer = []           — 先缓冲，避免丢帧
  7. listen(`agent://line/${id}`) / listen(`agent://exit/${id}`)
  8. invoke("replay_events", {sessionId, afterSeq: lastSeq})
     ├ dropped=true → 先 invoke("extension_ui_state") 覆盖 state.extWidgets（记 extSnapshotSeq）
     └ 逐条 _dispatchEnvelope(ev)
  9. 释放 _replayBuffer，逐条补发
 10. _initFetch()（live.js:2829）：
     negotiate_protocol(v2) → set_ask_dialog → (set_auto_compaction/retry 若关闭)
     → get_state / get_messages / get_available_models / get_available_commands
     → set_subagent_subscription / get_subagents
```

### C. 重启（不换 id）

```
_respawnSession(id, {profile, resume, fresh})                 live.js:1308
  → _respawning 守卫（防并发重入）
  → invoke("stop_session")        ← 不碰终端、不碰浏览器
  → registry 快照暂存，_spawnSession(id, entry.path, {profile, resume})
  → 新会话 processStartedAt 更新（会话树据此判定"冷缓存"）
  → 失败：note「Profile switch failed」/「Approval mode change failed」
  → 期间标签页被关闭 → _closeTab(id)
```

### D. 关闭

```
closeSession(id)
  → closeSessionGuarded（confirmBusyClose 开启且 isBusyRunState 时先确认）
  → _closeTab(id)（live.js:1217 — 唯一终止路径）
    → invoke("close_tab")                                   lib.rs:370
      → end_tabs([id])（lib.rs:348）
          bridge.stop_session(id, &rule_book)               → 杀 omp 树 + 清会话授权
          widgets.session_closed(id)
          watchers.stop(id)
          ‖ browser.release_many([id])    ← 与终端并行（thread::scope）
          ‖ terminal.close_tabs([id])
    → 丢弃该标签页在 JS 侧的所有绑定
```

### E. 启动恢复

```
live.js 启动
  → invoke("close_all_tabs")     ← 清掉上一份文档遗留的 omp/Chromium/shell（id 跨 reload 不复用）
  → _refreshProfiles()
  → _restoreOpenTabs()                                           live.js:1792
     ├ restoreTabs 关闭 → 什么也不读，_layoutArmed 直接 adopt 空布局
     └ 读取 open_tabs_load → Rust 过滤（文件夹消失丢弃、会话文件消失则开新会话）
        → 逐个 _startProjectSession(…, {activate:false, remember:false})
        → 每个 spawn 之后再决定激活（不打断用户此刻的选择）
  → _setupExternalOpens()
  → _layoutArmed = true（adopt 当前布局为"已写入"）
```

## 关键节点详解

| 节点 | 位置 | 核心逻辑 | 异常处理 |
|---|---|---|---|
| 审批模式解析 | `ApprovalModeStore::resolve` | 项目覆盖 → 否则全局默认 | 文件损坏 → 读默认 + 拒写 |
| 版本闸 | `agent/spawn.rs:91` | 解析 `omp --version` 首行 | 版本低/不可读 → 拒绝启动并给 `omp update` 提示 |
| 终端注册 | `TerminalManager::register_tab` | 先注册再 spawn，失败标签也有终端 | 重复注册保留 shell 槽位 |
| 浏览器分配 | `BrowserManager::allocate_if_available` | 绑 `127.0.0.1:0` + 写私有 overlay | 失败 → `start_session` 整体失败（前端回滚关闭标签页） |
| 事件重放 | `replay_events` + `EventJournal` | 256 条 / 8 MiB 环形 | `dropped` → `get_messages` + `extension_ui_state` 兜底 |
| 代际守卫 | `_switchGen` / `current()` | 每次 await 后校验 | 被取代的流程静默退出，不漏帧到新标签页 |
| 布局持久化 | `_persistLayout`（`live.js:707`） | 与上次 JSON 比较，变了才写；串行写，latest wins | 未 arm 前不写，避免用残缺集合覆盖文件 |
| 结束 | `end_tabs` | 浏览器与 shell 并行拆除 | 未知 id 合法（幂等） |

## 异常路径

| 异常 | 处理 |
|---|---|
| `omp` 不在 PATH / 版本过低 | `spawn_omp` 返回错误 → `cache_error` + 命令返回；前端记 `failed` 运行状态并显示注记；`session_status` 可再次查到原因 |
| spawn 后瞬间死亡 | stderr reader 收集有界尾部；reader 在"从未收到任何帧"时用尾部替代空 payload，避免被读成正常退出 |
| 浏览器分配失败 | `start_session` 失败 → 前端回滚（`close_tab`），绝不让标签页"悄悄没有浏览器"运行 |
| 恢复时文件夹已删除 | `open_tabs_load` 丢弃该标签页并在界面报 note |
| 恢复时会话文件不存在 | 以"新会话"重开该文件夹（不丢项目） |
| 重启时标签页已被关闭 | `_respawnSession` 检测到后调用 `_closeTab`，回收刚 spawn 的进程 |
| 重启时 `sessionFile` 不存在 | 退化为无 `--resume` 的新会话（唯一会丢上下文的情形） |
| 重启后模式仍不符 | 记入 `_modeRestartMissed`，目标模式变化前不再重试（防重启风暴） |
| 忙碌标签被关闭 | `confirmBusyClose` 开启时弹确认；否则直接关闭（与旧行为一致） |
| 退出/安装更新 | `kill_child_processes`（`lib.rs:1219`）按序停远程服务 → omp → Chromium → widget → shell |
