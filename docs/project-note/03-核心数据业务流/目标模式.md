# 目标模式（goal）

omp 的 goal 模式：一个带 token 预算的持续目标，omp 在每轮之间自动继续（需 `goal.continuationModes` 含 `"rpc"`）。

## 触发点

| 触发 | 入口 | 前置 |
|---|---|---|
| 建立 goal | composer 的 goal 药丸 → `OMP_BRIDGE.goalStart` | 未在 plan 模式，且本标签页没有 active/paused/budget-limited 的 goal |
| 恢复 / 暂停 / 放弃 | `goalOp`（`resume`/`pause`/`drop`） | goal 已知 |
| 自动继续开关 | Settings → Agent `goalContinue` → `goal_continuation_set` | 需要 `omp` 二进制 |
| omp 自行开始 | `goal create` 后 omp 可能直接开跑 | — |

## 数据流路径

```
用户建 goal
  → OMP_GOAL 校验（预算、目标文本）
  → OMP_BRIDGE.goalStart → { type:"goal", action:"create", objective, token_budget }
  → omp 应答 → get_state（取 goal 状态与 isSettled）
  → 若 omp 未自行开跑（ompStartedTurn 为假）：
       把 objective 作为首条 prompt 发出
       · omp 未 unsettled → 直接 prompt
       · omp unsettled     → 进队列，但帧仍是 prompt + streamingBehavior:"steer"
                             （只有 prompt 路径会附带 goal 上下文）
  运行中
  → omp 每次变化发 goal_updated {goal, state?}
     → OMP_GOAL.fromFrame(state.goal, ev, {stopping: userAbortInFlight})
     → 状态 + 可能的转录行（仅在标签页"已知"过 goal 时才生成行）
  → 完成：omp 发 status:"complete" → 该轮结束后 omp 清空 goal（get_state.goal = null）
      → reducer 保留完成记录，直到 dismiss / 新 goal / 转录重置
  → abort：omp 暂停 goal，只有 `goal resume` 能重启
      → userAbortInFlight 让这次暂停被标注为"用户停止"
```

## 关键节点详解

| 节点 | 位置 | 核心逻辑 | 异常处理 |
|---|---|---|---|
| 行生成条件 | `GOAL.fromFrame` | 只在 tab 已 `known` 时生成行 | 新/重启进程在首次 `get_state` 前上报的 goal 变化保持静默 |
| 完成态保持 | `GOAL` reducer | 完成记录跨 `null` 快照保留 | `dismissedId` 记住被忽略的 id |
| 自动继续配置 | `goal_config.rs` → `omp_cli::run` | 读写 `omp config get/set goal.continuationModes`，只改 `"rpc"` 项 | profile 必须先过 `resolve_owned`（否则 omp 会隐式创建该 profile 目录） |
| 开跑判定 | `live.js` `ompStartedTurn` | streaming，或未 settled 且无背景任务、无排队消息 | 有 follow-up 等待时 omp 会跳过继续 → 按"未开跑"处理 |
| plan 互斥 | `OMP_GOAL` + 组件 | goal 激活/暂停/超预算时禁 plan；plan 开启时禁 goal | omp 自己也拒绝两者并存 |

## 异常路径

| 异常 | 处理 |
|---|---|
| omp 未自行开跑 | 由前端补发首条 prompt（带 goal 上下文） |
| omp 处于 unsettled | 走队列，避免目标出现两次 |
| 预算超限 | 状态翻 `budget-limited`；恢复的 goal 已超预算时不会被 abort 暂停 |
| 用户 abort | goal 暂停并标为"用户停止"；`abort resume` 前不自动继续 |
| goal 工具审批 | omp 的 `goal` 工具未声明审批层级 → 落到 `exec`，在 `always-ask`/`write` 下会弹"Allow tool: goal"（上游 omp #14368）；`yolo` 不问 |
| 改预算 | 只能在 `create` 时设定（omp 终端专属能力） |
| 标签页重启 | 行消失（live-only），omp 重新上报 goal 状态 |

## 关联组件

- 纯逻辑：`OMP_GOAL`（`UNKNOWN`、`fromFrame`、行模型）
- 状态（每标签页）：`state.goal`；React `useGoalMode` 的 `{mode, budget, error}`
- Rust：`goal_config.rs`、`omp_cli.rs`
- 命令：`goal`（RPC）、`goal_continuation_get` / `goal_continuation_set`（Tauri）
- 组件：`design/goal-strip.jsx`、`design/chat/goal-row.jsx`
