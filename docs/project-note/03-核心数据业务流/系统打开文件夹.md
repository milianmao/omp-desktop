# 从系统打开文件夹（Open with OMP Desktop）

用户从 Finder / 资源管理器 / 文件管理器把一个文件夹交给本应用，应用打开（或聚焦已存在的）该项目标签页。

## 触发点

| 平台 | 投递方式 | 注册位置 |
|---|---|---|
| macOS | `RunEvent::Opened { urls }`（因此 `run()` 用 `build().run(cb)` 而非 `Builder::run`） | `packaging/Info.plist`（`CFBundleDocumentTypes`、`public.folder`、rank `Alternate`） |
| Windows | 以文件夹为 argv 启动可执行文件；由单实例插件转发给运行中的实例 | `packaging/windows-folder-verb.nsh`（NSIS）+ `.wxs`（MSI），`Directory\shell` / `Directory\Background\shell` |
| Linux | 同 Windows | `packaging/omp-desktop.desktop`（`MimeType=inode/directory`，`Exec` 必带 `%F`） |

## 数据流路径

```
OS 投递
  → 冷启动: setup 读 args_os() 的第一个参数
  → 热转发: tauri-plugin-single-instance 把 argv 交给运行中实例
  → macOS: RunEvent::Opened { urls }
        ↓
  external_open.rs 收入队列 OpenProjectState（上限 32）
  → emit("open://project")（无 payload —— **队列才是事实源**）
        ↓
  live.js _drainExternalOpens
     · 串行化每次 drain（每次 open 都会切活动标签页）
     · 每个 open 独立 try/catch（一个失败不能丢掉已取出的整批）
     · 事件在守卫期间到达 → 记 _externalOpenWake，drain 结束前必须再 take 一次
  → take_pending_open_projects() 清空队列 → 逐个 openProject(path)
  → 已有该项目标签页则聚焦，否则新建
```

### 启动顺序

```
_refreshProfiles() → _restoreOpenTabs() → _setupExternalOpens()
```

冷启动带来的"Open with"在恢复标签页之后打开，并成为活动标签页。

## 关键节点详解

| 节点 | 位置 | 核心逻辑 | 异常处理 |
|---|---|---|---|
| 路径规范化 | `external_open::canonical_folder` | 去掉 Windows 的 `\\?\` 前缀（gix 与 omp 都不吃）；相对路径按"argv 产生时的目录"拼接 | 非目录/不存在 → 记日志丢弃 |
| 队列 | `OpenProjectState`（上限 32） | `take_pending` 是唯一取用方式，天然幂等 | 满了丢最旧 |
| 事件 | `open://project` | 无 payload，不需要请求 id 与 ack | — |
| 去重 | `openProject` → `findProjectTab` | 已有该（profile, folder）标签页则聚焦 | 路径形式必须已规范化，否则匹配不上 |
| 冷启动 argv | `std::env::args_os()` | `std::env::args()` 在非 UTF-8 参数上 **panic** | — |

## 异常路径

| 异常 | 处理 |
|---|---|
| 传入路径不是目录 / 不存在 | 记日志并丢弃，不打断其它请求 |
| 相对路径 | 拼接到 argv 产生时的目录（不是当前进程 cwd） |
| 打开失败 | 该次单独失败，其余批次继续 |
| 用户在 drain 期间再投递 | `_externalOpenWake` 保证再 take 一次（丢失窗口不是同步的：Rust 在 `take_pending` 释放锁时就清空了队列） |
| Linux 非 UTF-8 文件夹名（热转发） | **已知限制**：单实例插件在*发送*进程里自己收集 `std::env::args()`，会在到达我们之前 abort 该进程（插件限制） |
| `.desktop` 缺 `%F` | 冷启动收到空 argv，"Open with" 静默打开一个空应用 |

## 关联组件

- Rust：`external_open.rs`、`lib.rs` `setup`（argv 摄入）、`tauri-plugin-single-instance`
- 前端：`live.js` `_drainExternalOpens`、`OMP_BRIDGE.openProject`
- 命令：`open_project`（文件夹选择器，同样做 canonicalise）、`take_pending_open_projects`
- 打包：`packaging/{Info.plist,omp-desktop.desktop,windows-folder-verb.nsh,windows-folder-verb.wxs}`
