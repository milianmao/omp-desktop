## 快速判断

| 我要做的事 | 该走的通道 |
|---|---|
| 让前端知道 Rust 的状态变化 | Tauri event（`xxx://…`），不要轮询命令 |
| 让 Rust 做事 | Tauri command，参数 camelCase，错误 `String` |
| 让 omp 做事 | RPC 命令，且必须先进 `ALLOWED_COMMAND_TYPES` |
| 加纯逻辑 | `src/app/<name>.js` + `window.OMP_*` + `tests/test-<name>.mjs` |
| 加 UI | `src/design/**`，并按依赖顺序插入 `src/index.html` |
