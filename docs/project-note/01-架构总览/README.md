## 三句话概括

1. 一个标签页 = 一个 `omp --mode rpc-ui` 子进程；Rust 管进程与文件，`src/live.js` 管每个标签页的状态机，React 只负责渲染。
2. `src/` 不打包，`src/index.html` 的 `<script>` 顺序就是依赖图；release 才用 `dist/` 预编译产物。
3. 所有"策略"（用哪个 shell、哪个浏览器、哪个审批模式、哪条 widget 命令能跑）都住在 Rust 里，webview 只发送 id、尺寸、输入和视图状态。
